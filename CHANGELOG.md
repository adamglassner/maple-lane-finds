# Changelog

Each version's bullet points are shown to players in the in-game "update available" window,
so write them in plain, friendly language.

## v1.0.0
- First release of Maple Lane Finds!
- Five cozy autumn scenes to search, with ten hidden items each.
- Five puzzles: Pumpkin Pairs, Barn Differences, Pie Picture Slide, Corn Maze Path and Harvest Code.
- Relaxed, Normal and Challenge modes, adjustable text size, music and sound volume.
